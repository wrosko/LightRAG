## Key Architecture Decisions:

### Schema Design:
```cypher
CREATE NODE TABLE Entity(
    entity_id STRING PRIMARY KEY,
    entity_type STRING,
    description STRING,
    source_id STRING,
    content STRING
);

CREATE REL TABLE DIRECTED(
    FROM Entity TO Entity,
    weight DOUBLE,
    source_id STRING,
    description STRING,
    keywords STRING
);
```

### Bidirectional Edge Strategy:
- Since Kuzu requires directed relationships, we create both directions
- `MERGE (a)-[r1:DIRECTED]->(b)` and `MERGE (b)-[r2:DIRECTED]->(a)`
- Maintains undirected graph semantics for LightRAG

### Storage Modes:
- **In-memory**: `Kuzu.Database()` - fast, temporary
- **File-based**: `Kuzu.Database(path)` with `KUZU_DB_PATH` env var
- **Workspace isolation**: `KUZU_DB_PATH/namespace/workspace.kuzu`
